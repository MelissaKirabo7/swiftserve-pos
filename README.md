# SwiftServe POS

Role & Goal You are an expert full-stack developer and UI/UX designer. Build a modern, highly responsive Point of Sale (POS) web application based strictly on the provided Requirements Document and Excel dataset.

Core Workflow & Data Source

Database & Logic: Use the attached Requirements Document to establish the core feature requirements, user roles, business logic, checkout flow, and validation rules.

Data Schema & Mock Data: Use the attached Excel Sheet to define the data structures (e.g., inventory items, pricing, categories, tax rates, customer data) and pre-populate the application with realistic seed data.

Key Features & Functionality

Fast Checkout / Register Interface:

Clean layout with a searchable/filterable product grid or list by category.

Real-time shopping cart panel allowing quantity edits, line-item discounts, and single-click item removal.

Quick-action payment modal supporting multiple payment methods (Cash, Card, Digital Wallet, Split Payment).

Inventory Management:

Stock tracking, low-stock indicators, and real-time updates when sales are processed.

Search, filter, and quick-edit capabilities for prices and stock levels.

Order & Transaction History:

Searchable order history log showing complete receipts, payment statuses, and refund/void options.

Receipt & Reporting:

Digital receipt generator (printable or preview modal).

High-level summary dashboard displaying daily sales totals, transaction counts, and top-selling items.

Design & UI/UX Guidelines

Style: Clean, high-contrast, modern UI optimized for fast touch-screen or keyboard interactions.

Layout: Dual-panel split screen (Main area for products/actions, persistent side panel for the active cart).

Usability: High-visibility totals, prominent primary payment buttons, and clear visual feedback for added items. For reference, use the images attached
